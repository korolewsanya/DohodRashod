### 🎯 Что сделано:
- Android-приложение для учёта личных доходов и расходов
- Ввод сумм, выбор и создание категорий
- Просмотр, редактирование и удаление записей
- Удаление нескольких записей сразу через чекбоксы
- Сравнение доходов и расходов по месяцам
- Все данные хранятся локально в SQLite (без интернета)

---

### 🏗 Архитектура проекта

Приложение разделено на **3 логических модуля**:

#### 💵 Доходы
Ввод суммы, выбор категории («Основной доход», «Дополнительный заработок» или своя), просмотр истории, редактирование и удаление.

#### 💸 Расходы
Ввод суммы, выбор категории («Продукты», «Оплата ЖКУ» или своя), просмотр истории, редактирование и удаление.

#### 📊 Сравнение
Сводная информация по доходам и расходам за месяц/год.

### 📂 Структура проекта

```
com.example.dohodrashod
├── Glav.java                — главный экран
├── WodDoh / WodRas          — ввод дохода/расхода
├── SohDoh / SohRas          — выбор категории
├── SozPapki / SozPapkiRas   — создание категории
├── ProsmotDoh / ProsmotRas  — просмотр записей
├── RedactDoh / RedactRas    — редактирование
├── UdDoh / UdRas            — удаление (в т.ч. массовое)
├── Sravni.java              — сравнение
├── DatabaseHelper.java      — работа с SQLite
├── CustomDialog.java        — диалог «пустое поле»
└── CustomDialog2.java       — диалог «неверная дата»
```

### 📌 О проекте

> Проект разработан как портфолио-решение для демонстрации навыков разработки под **Android на Java**. Показывает работу с локальной базой данных SQLite, навигацией между Activity, обработкой списков и адаптеров, диалоговыми окнами и решением проблем совместимости с новыми версиями Android (11, 12, 16).
